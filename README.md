# Veni Vidi Vici · Site

Protótipo do site da marca Veni Vidi Vici (VVV): página inicial com a Coleção I · Veni, edição Vici, lista de espera e tela da sacola.

## Como abrir

É uma página estática, sem dependências. Abra o `index.html` no navegador.

- Página inicial: `index.html`
- Sacola: `index.html#sacola`

## Estrutura

- `index.html`: página completa (HTML, CSS e JavaScript no mesmo arquivo, com os logos embutidos).
- `assets/logos/`: kit de logos em SVG e PNG (coroa de louros, monograma e tipografia, em 5 versões de cor).

## Identidade

- Fontes: Cinzel (títulos) e Cormorant Garamond (textos), via Google Fonts.
- Cores: preto `#0F0E0C`, dourado `#C69F5B`, branco `#FFFFFF`.

## Provisório

Fotos das peças, preços, regras de frete (grátis acima de R$ 500), parcelamento (6x) e o cupom de teste `VENI10` são exemplos. O formulário e o botão de finalizar compra não enviam nada.
